# OutCore

Визуальный движок сервера Outbreak SMP (Spigot/Arclight). Градиентные ники по группам LuckPerms, лица игроков прямо в чате и приватные могилы с таймером. Работает без Adventure — градиенты рендерятся вручную в legacy `§x`-hex, поэтому живёт на любом Spigot 1.16+.

## Возможности
- Плавный градиент ника по символам, цвет берётся от группы с наибольшим весом
- Префиксы и суффиксы LuckPerms читаются вживую, без перезахода
- Лица игроков в чате: битмап-шрифт из ресурс-пака, `heads.yml` подхватывается на лету
- Ресурс-пак пушится только при смене версии — иначе ломается стейт TACZ
- Приватные могилы: сундук на месте смерти, виртуальное хранилище на 54 слота
- Таймер жизни могилы с голограммой обратного отсчёта над сундуком
- Компас-локатор на точку смерти и координаты в чат при респавне
- Раскраска ников в сообщениях о смерти поверх DeathMessages

## Плейсхолдеры
`%outcore_head%` · `%outcore_name%` · `%outcore_boldname%`
Старый префикс `%wardenchat_*%` тоже зарегистрирован — для совместимости с конфигом TAB.

## Сборка
`mvn clean package` (JDK 21)
